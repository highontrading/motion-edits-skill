**One-line essence:** a software launch told entirely through the product's own UI (plugin panel, AE timeline, AI prompt box). The UI sits on a black "hacker HUD" set of grid lines, ASCII glyph matrices and typing code snippets, with one acid-lime accent that glows wherever the user is meant to look. ## 1. Concept & script structure
- **Genre:** SaaS/plugin launch promo, structured as a "prompt → result" demo loop (tutorial-promo).
- **Beats:**
  - 0.0–1.54 **Hook / title:** a glyph strobe resolves into the "Higgsfield" wordmark, then "IS NOW ON / After Effect X Premiere Pro" in a HUD layout.
  - 1.54–5.62 **Product intro:** the plugin panel UI, then the "Adobe After Effect" title card with app icons and the real AE window, then the AE timeline where a clip is dragged in.
  - 5.62–13.46 **Demo 1 (morph):** source clip → typed prompt "Seamlessly morph the background into the moon's surface" → morph result → "Draw to Video" scribble.
  - 13.46–19.54 **Demo 2 (remove BG):** woman on the moon → prompt "Keep the character and remove the background." → woman in a white infinite room walks away.
  - 19.54–26.2 **Demo 3 (back home + upscale + reframe):** prompt "Bring him back to Earth, back to his home" → timeline clip lands → bedroom result with an "Upscale" scan wipe → prompt "Make the video 1080 X 1920".
  - 26.2–30.1 **Payoff + CTA:** the frame physically reframes into a 9:16 panel, which demonstrates the last prompt and becomes the end card ("HIGGSFIELD PLUGIN ON HIGGSFIELD.AI", "HIGGSFIELD × EARNEDITS", "Comment 'AI' / For Free PROJECT FILE & TUTORIAL").
- **Hook mechanics:** the first 0.42 s is a **10-frame strobe**. Frames alternate between near-black with a single glyph (`<`, `!`, `%`, `()`, `|`) surrounded by lime and blue pixel squares, and **full white flash frames** at f2, f4 and f10 (luma 237–247 vs 10). The eye is hit four times before any word appears. The last flash reveals "Higgsfield" typing on with an I-beam cursor.
- **Content → visual rule:** each feature equals one prompt card (typed live) followed by one result clip, with a lime flash between them. Feature names appear only as small lime pill tags on the result ("Draw to Video", "Upscale"), never as big titles.

## 2. Visual language
- **Art direction:** dark-mode UI mockup plus a tech HUD. The set is a black field `#030201`–`#0d0d12` with thin grey grid lines (a ~3×3 layout grid at ~15% opacity). It carries a dim **ASCII/glyph-matrix texture** (rows of "A", ⚙ and ◇ glyphs at ~10–20% opacity) and floating **code snippets in monospace** that type on in the margins (`seedRandom(index, true);`, `wiggle(7,0.3)`, `amplitude = 5; frequency = 0.2;`, `// Smaller for su…`). These are AE expression jokes for an editor audience. The real product UI (panel, AE window, timeline, prompt box) floats in this space with soft shadows and lime under-glow.
- **Footage integration:** AI-generated videos (man in a hoodie, moon, woman in a green hoodie, white room, bedroom) are shown **inside the AE composition viewer**: the AE toolbar (`0:00:01:13`, "Draft 3D", "Classic 3D") stays visible at the bottom edge, so the result reads as "rendered in your timeline". Overlays on the footage: tilted lime pill tags, a thick lime scribble stroke drawn over the subject (Draw-to-Video input), a white vertical scan line (upscale before/after), and a translucent prompt card docked at the bottom. There is no tracking or roto; overlays are screen-locked and the subject is centred.
- **Colour:** essentially **black + white + one acid lime `#d2fa18`/`#d5ed21`/`#c3da17`** (k-means also shows `#4d5412` and `#636c31` for the glow falloff). Lime marks every action: wordmark, NEW badge, send button, card borders, pill tags, scribble, glows, highlight boxes, and the URL in the end card. Secondary colours appear only inside the AE timeline layer bars (salmon `#d98a8a`, pink `#e8b4c0`, mustard `#c9b74a`, periwinkle `#8a8fd8`, AE's own label colours) and as a red strobe glyph in the intro. Footage is graded cool and dark (blue-grey moon `#5a5f61`, white room `#d8d2d7`), so the lime stays the hottest thing on screen.

## 4. Motion & timing analysis
- **Pacing:** ~0.55 cuts/s; shots 0.33–3.9 s. The intro is frantic (6 states in 1.5 s), the demos settle into a steady **prompt (~2.2 s) → result (~1.6–3.9 s)** rhythm, and the end card holds ~4 s.
- **Easing signatures (measured at 24 fps):**
  - UI card entrances are a **hard ease-out**: velocity peaks on the first frame and halves every ~1.5 frames, settling in 5–8 frames (AE window: 5.1 → 3.2 → 1.5 → 1.1 → 0.7). Use `spring({damping: 26, stiffness: 260, mass: 0.6})` or `Easing.out(Easing.exp)` over 8 frames.
  - The **momentum cut** is used at 7.375, 9.54 and 17.25. The outgoing shot accelerates in one direction over 4 frames (velocity ×3–6, ease-in), the cut lands at peak velocity, and the incoming shot keeps the same direction and decelerates to ~0.15× over 5–6 frames (ease-out). Total ≈ 10 frames.
  - Pill tags and icons use a **scale pop with slight overshoot** (0 → 1.1 → 1 over ~4 frames).
  - Scribble and scan line use a **linear draw** (15 frames and 13 frames).
  - Stepped camera on timeline macros: single-frame zoom jolts every 2–3 frames (3.9–5.6), which makes it look hand-keyed and "edited".
- **Entrance / exit vocab:** glyph strobe; typewriter with caret (wordmark, titles, prompts at 40–50 chars/s); **backspace erase** as an exit; chip scale-from-0 width; icon pop with a 2-frame stagger; stacked glow-rectangle scale-up; staggered horizontal layer-bar slides; drag-and-drop with a cursor; pill pop (tilted); scribble draw-on; scan-line wipe; prompt card fade+scale-in from 0.95; mask-collapse reframe.
- **Camera:** mostly locked UI with slow linear drifts (pan_y −14 over 1.6 s on the panel; pan_x +17 on footage). Punctuation comes from single-frame zoom jolts, one zoom-through (5.46–5.6, rot 7°/frame), one punch-in (2× at 20.42) and one 0.3 s shake (22.33–22.63).
- **Secondary motion:** code snippets typing in the margins, ASCII matrix flicker, lime glows breathing behind the UI, and the cursor ripple on click.
- **Sync (music-only, 123 BPM):** 13 of 15 real cuts fall within ±0.2 s of a beat, and 8 fall within ±0.05 s: 1.54 (beat 1.49), 13.46 (13.51), 15.08 (15.07), 19.54 (19.50), 20.42 (20.46), 21.42 (21.41), 26.20 (26.21), 22.67 (strong onset 22.62). The intro strobe is locked to the first downbeat/onset at 0.51. The strong-onset run 24.78–25.73 lines up with the scan wipe and the prompt typing, and 27.66–28.6 with the end-card label pops. Prompt typing duration is fitted to ~2–3 beats (1.0–1.3 s), and the send-button bloom lands on a beat (8.68, 16.14 ±0.1).

## 5. Transitions catalogue
1. **Strobe flash intro** (0.08, 0.17, 0.42): full-white single frames alternating with black glyph frames. Rebuild: in the first 10 frames, `frame % 2 === 0 ? white : glyphFrame`, with the glyph picked from a set each frame.
2. **Backspace erase** (1.33–1.50): the title is deleted right-to-left at ~2 chars/frame, then a hard cut. It is a typographic exit that feels like an edit.
3. **Momentum cut** (7.375 horizontal; 9.54 and 17.25 vertical): ease-in drift on the outgoing shot (4 frames) → cut at peak → ease-out drift on the incoming shot (5–6 frames). Rebuild: one shared `offset(t)` curve with `bezier(0.5, 0, 0.5, 1)` over 10 frames, applied to both scenes (outgoing for frames 0–4, incoming for 5–10). Add 6–10 px directional blur at the peak.
4. **Zoom-through with rotation** (5.46–5.62): 4 frames of scale ×1.25/frame plus rotation 2–7°/frame into the AE viewer, cutting to the footage at full blur.
5. **Lime halftone flash** (13.46, 17.25): the first ~6 frames of a result shot carry a lime dot-grid vignette (dots ~6 px, pitch ~14 px, strongest at the edges, `screen` blend) that fades to 0. It is the brand's "AI magic happened" signature.
6. **Punch-in cut** (20.42): the same UI at ~2× scale, cutting straight to the important area (send button).
7. **Shake-out** (22.33–22.63): ~7 frames of alternating ±zoom/rotation jitter on the timeline, then a cut on the onset.
8. **Scan-line wipe** (23.75–24.3): a white 2 px vertical line crosses L→R over ~13 frames, showing the before/after of upscaling.
9. **Mask-collapse reframe to 9:16** (26.2–26.75): the 16:9 shot's mask skews and narrows into a slanted parallelogram, then straightens into a centred vertical panel while the end-card text frames it. This transition literally demonstrates the "Reframe" feature.

## 7. What makes it high-end (the transferable lessons)
1. **One accent colour that means "action".** Lime marks only interactive or important things (send button, NEW chip, tags, glows, URL). Everything else is black, white and grey.
2. **Show the real product UI, but stage it.** Float real screenshots on a designed HUD set (grid, ASCII matrix, code margins) instead of showing a raw screen recording.
3. **Prompt → result is the beat structure.** A typed prompt (~1–1.3 s, on 2–3 beats) and a send-button bloom on the beat, then a lime flash and the result. The repetition teaches the product.
4. **Type that edits itself:** typewriter carets, backspace exits and glyph scrambles feel native to a software audience.
5. **Momentum cuts** connect dissimilar UI and footage shots by sharing one motion curve across the cut.
6. **Results stay in context:** footage is shown inside the AE viewer with the toolbar visible, which says "this happened in your timeline".
7. **The last transition is the last feature:** the reframe-to-9:16 move both demonstrates the feature and builds the CTA layout.
8. **Insider jokes in the texture** (AE expressions like `wiggle(7,0.3)` in the margins) signal "made by editors for editors".

## 8. Remotion rebuild recipe
- **Composition:** `1920×1080`, `24 fps` (or 30 with all frame counts ×1.25), 30 s = 720 frames. Make a 9:16 variant by reusing the end-card panel.
- **Layer stack (bottom → top):** `<HudBackground grid={3} glyphMatrix opacity={0.15} vignette>` → `<CodeMargins snippets typeSpeed={1.5 chars/frame}>` → `<LimeGlow x y radius={300} opacity={0.4}>` → UI layer (`<UICard src>` / `<AEViewer footage>` / `<PromptBox>`) → overlay tags (`<PillTag>`, `<Scribble>`, `<ScanLine>`) → `<HalftoneFlash>` → `<GrainOverlay opacity={0.04}>`.
- **Components:**
  - `GlyphStrobe({frames: 10, glyphs: ['<','!','%','()','|'], flashFrames: [2,4,10]})`.
  - `Typewriter({text, cps: 42, caret: '_' | '|', caretBlink: 12})` with `backspace({startFrame, cps: 48})` for erase exits.
  - `UICardIn`: `spring({damping: 26, stiffness: 260, mass: 0.6})` on `translateY 60→0` and `scale 0.96→1`, ~8 frames.
  - `StackedGlowFrames`: 3 lime rounded rects with `opacity .15/.25/.35` scaling `0.9→1.05` with a 2-frame stagger.
  - `LayerBarsSlideIn`: bars `translateX(-100%)→0`, `Easing.out(Easing.cubic)`, 6 frames each, stagger 2 frames, `box-shadow: 0 0 16px currentColor`.
  - `DragCursor({path, grabAt, dropAt})`: hand PNG with drop glow.
  - `SendBloom`: lime circle `box-shadow` radius 0 → 40 px → 12 px over 6 frames, on a beat frame.
  - `MomentumCut({axis: 'y', peak: 40 px/frame, framesIn: 4, framesOut: 6})`: one curve drives both sequences.
  - `HalftoneFlash`: SVG `<pattern>` dots in `#d2fa18`, masked by an inverted radial gradient (edges only), opacity `1→0` over 6 frames, `mix-blend-mode: screen`.
  - `PillTag({text, rotate: -10})`: `spring({damping: 12, stiffness: 200})` scale with ~1.1 overshoot.
  - `ScribbleDrawOn`: SVG path, `stroke-width: 40`, `stroke-linecap: round`, `strokeDashoffset` over 15 frames, fill pattern = halftone.
  - `ScanLineWipe`: 2 px white line `left: 0→100%` over 13 frames, linear; `clip-path` reveals the upscaled version on the left side.
  - `ReframeCollapse`: animate `clip-path: polygon()` from the full 16:9 rect → a skewed parallelogram (top edge offset +8%) → a centred 9:16 rect, 12 frames, `Easing.out(Easing.exp)`, with `rotate 0→2°→0`.
  - `HighlightLabel`: black mono text on a lime rect that wipes `scaleX 0→1` from the left in 4 frames.
- **Tricky effects:** for the stepped camera on timeline macros, keyframe `scale` and `translate` only on every 3rd frame (hold in between) and add single-frame 6–10% zoom jolts on beats. The glyph-matrix background is a canvas or SVG grid of characters whose opacity is randomised with a slow noise (`noise2D(x, y + frame*0.02)`).

## 9. Variation ideas
1. **AI SaaS launch (any tool):** keep the prompt → result loop and the single-accent HUD; swap lime for the brand colour and the AE viewer for the product's canvas; finish with a reframe or "export" gesture that builds the end card.
2. **Template/preset pack promo for editors:** the timeline macro shots, layer-bar slide-ins and drag-and-drop become the hero; results play inside the NLE viewer; code-margin jokes use the relevant software's expressions.
3. **Dev-tool or API announcement:** replace the footage results with terminal or code output; the backspace erase and glyph strobe carry the brand; each command typed on 2 beats, followed by a halftone flash and the rendered output.
