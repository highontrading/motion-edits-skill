**One-line essence:** a soft, pastel "AI product film". Every VO clause gets its own clean graphic world (3D ripple rings, glowing AI orb, chat bubbles, prompt bar, node graph, halftone dot grid, cosy footage), and each step of "prompt → app" is shown as text being typed into a rounded UI element, cut on the beat.

## 1. Concept & script structure
- **Genre:** sponsored no-code AI tool promo (Base44), with a creator CTA tacked on for the earn.edits project-file store.
- **Beats:**
  - 0.0–4.5 **Hook / claim:** "Base44 lets you build an actual app without knowing how to code." The logo builds, 3D rings ripple out, and an AI orb wakes up.
  - 4.9–9.9 **How (step 1):** describe your idea → a chat ("Hey, I want you to tell me what you wanna build" / "Make me an e-commerce app.") → a prompt bar with reference images dropped in → "Connecting" node graph.
  - 10.6–16.5 **What it builds:** a finished dashboard, then an "Automations" board (Login / Backend / Features / User Flow) built on the words "UI, database, login, backend, features"; a "make the design minimalist" prompt.
  - 17.3–21.5 **Benefit:** "handles the technical stuff in the background" → a live website (Nike shoe store) → a code-writing list → a "Building app" dot grid → cosy footage of a woman at a laptop with "On your idea".
  - 22.1–25.1 **Iteration:** "just tell Base44" → prompt bar "Perfect! No need for changes lets go with this" → logo end card.
  - 26.0–31.9 **Creator CTA:** "Editors, stop reverse engineering it. The full project file is on earnedits.com". A vortex of past project thumbnails, a slot-machine word reel landing on "Engineering It", the store screenshot with selection handles, and a flat-lay desk with a handwritten sticky note.
- **Hook mechanics (first 1.5 s):** a near-empty warm-grey frame `#ece3e3` with only the orange striped-sun Base44 mark. The wordmark types letter by letter on the VO ("Base" by 0.44 s, "Base44" by 0.67 s) and four tiny orange dots fade in at N/E/S/W around it like a loading constellation. At 1.50 s (VO "lets you") the frame explodes into huge 3D extruded concentric rings in a pink→orange→red gradient, rippling outward at a peak zoom of 3.0 px/frame. The hook is a quiet → loud contrast within 1.5 s.
- **Script → visual rule:** one clause = one graphic world, and the world is always a UI metaphor for that clause (describe → chat bubbles; turning into an app → a node graph "Connecting"; database/login/backend → labelled flow rows; in the background → a scrolling code log; your idea → a human at a laptop). Spoken product names appear as typed type ("Base44", "Automations", "Nike Shoe", "Engineering It", "Earnedits.com").

## 2. Visual language
- **Art direction:** soft-UI product film. Flat, rounded UI components (chat bubbles, prompt bars, pills, cards) on very light neutral grounds, punctuated by three "texture worlds": 3D extruded gradient rings, a retro halftone dot grid, and photographic footage / flat-lay. It feels like Apple/Linear marketing with a warm, crafty twist.
- **Backgrounds & textures:**
  - Warm light grey `#ebe8ec` / `#eae7eb` for every UI scene (no grid, no grain), and pure white `#fefefe` for logo cards.
  - Pastel lilac `#faddf7` behind the rings; the rings are shaded with a gradient `#fac0cc` → `#f77d6d` → `#f85739` → pure red on the inner walls, with a soft inner shadow (a clay-like 3D look).
  - Mustard paper `#edce93` with large halftone-screened dots in rows (amber `#d7a65f`, orange `#d16834`, olive `#6b6a3e`, brown `#7b4a35`), which looks like a risograph print. The dots fill in row by row.
  - The node graph uses a scatter of flat squares (orange `#e9672a`, crimson `#c8213a`, olive `#9b8f20`, teal `#2f5f58`, navy `#1f3c5a`, peach `#f0c2a0`), some filled with product photos, joined by 1 px grey lines.
  - Footage: an AI-generated/stock cosy room (warm window light, plants, knitted sweater), and a dark moody "coder at night" photo in the Automations split.
  - End card: a top-down desk shot on blue grid paper with collectibles (Charizard card, LEGO Emmet + Batman, PS3 pad, Joy-Cons).
- **Colour:** neutral warm greys and whites carry ~80% of the runtime. The brand accent is **Base44 orange `#f96c32` / `#fd6120`** (logo, ring tones, caret, send-button press state `#a87158`). Secondary accents appear only inside UI content: lime `#d4f53c`, lavender `#a1b5eb`, amber `#f2a93b`, blue `#3d5af1`. Type is near-black `#1d1b1f` on light grounds; white type appears only on the rings and on the footage pill.
- **Typography:**
  - Product/UI font: a clean geometric-humanist grotesk (Base44 is a Wix product, so likely **Wix Madefor Display/Text**; Figtree or Inter are close substitutes). Regular/Medium weight, sentence case, tight default tracking.
  - Sizes vary a lot by scene: the chat opener "Hey" typed at ≈ 18% of frame width per word (cap height ≈ 10% of frame height) in a large bubble; prompt-bar text ≈ 2.5–3% of frame height (the bar is ≈ 60% of width); "Automations" title ≈ 32% of width; "Editors stop reverse" ≈ 19% of width (Regular, `#222`); the word reel at ≈ 4.5% of frame height per line.
  - Code log: monospace (**Roboto Mono / JetBrains Mono-like**) for "</> Writing" in large grey `#c9c6c9`, with the active row black. File paths sit in grey pills.
  - Footage caption: white Medium in a **glass pill** (frosted, ~20% white fill, 1 px white 50% stroke, fully rounded, a pink glow sweeping across it on entry).
  - Sticky note: a casual handwriting font (Gochi Hand / Patrick Hand-like) in dark grey on yellow `#ddbb13`, with a star outline icon.
  - **Emphasis rule:** nothing is bolded or coloured. Emphasis is the active state: the typed caret is orange, the reel's centre word is black (others light grey), and the code list's active row is black.
- **Layout & composition:** strict centre framing. The UI element sits on the centre line and occupies 40–60% of the width, with oceans of negative space. Split layouts appear twice (photo left / UI board right; screenshot + type left/right). Orange square **selection handles** at the 4 corners of the store screenshot frame it like a design-tool selection.
- **Assets:** Base44 logo, chat UI, prompt bar UI, product photos (sneakers, vases, headphones, cameras), a dashboard mock, an Automations flow board, the Nike store mock, a code-writing log, AI/stock footage, a 3D gradient orb, 3D rings, previous earn.edits project thumbnails, the earnedits.com mobile screenshot, a desk flat-lay photo, and a hand/arrow cursor.
- **Finishing / FX:** a soft white outer glow around the orb (~30 px), mild drop shadows on bars (y 4 px, blur 12 px, 8%), a pink light-sweep on the glass pill and prompt bar edges, a fine halftone screen inside the dots, motion blur on the vortex cards, depth-of-field blur on the edges of the 3D-tilted board, and slight film grain/softness on the footage and flat-lay.

## 4. Motion & timing analysis
- **Pacing:** ~0.66 cuts/s (21 real shots in 31.9 s), shots 0.6–3.0 s, median ~1.3 s. The opening and the CTA are fastest (0.6–1.3 s); the Automations board holds longest (3.0 s) because it is built on three spoken keywords.
- **Cut ↔ beat sync:** at 96 BPM, 12 of 21 cuts land within ±0.11 s of a beat (11.50 −0.03, 14.50 +0.06, 19.61 −0.04, 20.89 +0.06, 22.17 +0.01, 24.06 0.00, 28.39 −0.01, 30.83 −0.09). The editor snaps clause-start cuts to the nearest beat, so cuts sit up to ±0.2 s from the first word (e.g. 14.50 vs "you" 14.72, 10.67 vs "From" 10.56).
- **Cut ↔ VO:** keywords are typed when spoken: "Base44" both times, the Login/Backend/Features rows within ±1 frame of their words, "Engineering It" landing 0.3 s after the spoken word, and "The Full / Project File" in step with the VO.
- **Easing signatures (per_frame.csv, 18 fps):**
  - **Burst-then-glide** (rings 1.50 s): zoom 0.52 → 1.38 → **3.01** (peak at frame 2) → 2.19 → 1.32 → 0.68, then a steady 0.45–0.6/frame push. That is a 2-frame attack, a ~4-frame decay to a constant velocity, i.e. an expo ease-out into a linear push.
  - **Settle-zoom on cut** (dashboard 10.67 s): zoom +1.96 → 0.91 → 0.83 → 0.61 → 0.45 → ~0.25 (exponential, ≈ ×0.75 per frame), never reaching zero within the shot.
  - **3D swing** (12.2–12.6 s): pan_x −0.64 → −1.0 → −1.9 → −4.3 → −4.6 → −3.0 → −1.8 → −1.4: an ease-in-out over ~8 frames (0.45 s), peak in the middle, no overshoot.
  - **Slide-up settle** (end card 29.67): pan_y −4.9 → −4.6 → −2.0 → −1.5 → −1.2 → −0.95 → −0.82: ease-out with a long tail.
  - Pops (squares, icons, dots) are 1–2 frames at 18 fps, i.e. effectively instant scale-ins with a tiny overshoot visible on the node squares.
- **Entrance / exit vocabulary:** letter-by-letter typing (logos, titles, prompts, sticky note); ripple ring burst; orb grow + morph to avatar; chat bubble drift-up; image stack fly-in to attachment slots; bar-collapses-to-pill; staggered square pops with connector lines; row-by-row halftone fill; continuous log scroll; slot-machine reel; thumbnail vortex; glass-pill light-sweep; selection-handle frame; slide-up settle.
- **Camera:** mostly locked-off flat UI with three kinds of camera move: (1) a constant push in hero shapes (rings, dashboard), (2) 3D perspective swings on a flat board (Automations), (3) punch-in reframes on stressed moments (prompt 23.1 s, sticky note 30.83 s).
- **Secondary motion:** the swirling orb interior, the spinner in pills, the bobbing orange arrow cursor, thumbnails flickering in the code log, and the hand cursor gliding to the send button with a ~4-frame ease-out before each click.

## 5. Transitions catalogue
1. **Quiet-to-loud hard cut** (1.50 s): a near-empty logo frame cuts to a full-frame saturated 3D ripple that bursts in 2 frames. Rebuild: a hard cut + `scale 0.9 → 1.08` in 2 frames, then a linear push of 0.3%/frame.
2. **Shape-becomes-UI morph** (3.72, 9.11, 16.83 s): the orb shrinks into the chat avatar; the prompt bar collapses into the "Connect" pill; a placeholder orange square grows into the website's hero tile. Each takes ~3–4 frames with shared position/colour. Rebuild: animate one element's `width/height/borderRadius/x/y` between the two layouts (FLIP-style) and cross-fade its contents at the midpoint.
3. **Zoom-out / punch-in reframe** (4.33, 23.1, 30.83 s): a 1-frame hard scale change (×0.35 out; ×1.6 in) on the same layout, always on a beat or the end of a word.
4. **Beat-locked hard cuts between worlds** (11.50, 14.50, 19.61, 20.89, 22.17, 24.06, 28.39 s): plain cuts, with no transition graphics, timed to the beat grid.
5. **Thumbnail vortex** (26.11–27.44 s): cards enter from outside the frame on a spiral path (rotation −30° → 0°, radius shrinking from ~900 px to ~420 px), motion-blurred, and settle into an orbit around the central text. Rebuild: for each card `angle = a0 + spring*θ`, `r = lerp(900, 420, spring)`, `rotate = lerp(-30, 0)`, staggered 1 frame per card.
6. **Slot-machine reel** (27.44–28.39 s): a vertical word list moves at ~1 line/frame and decelerates (ease-out over ~10 frames) to land on the keyword. Rebuild: `translateY = -lineH * Easing.out(Easing.cubic)(t) * N`, colour = black at the centre slot, else `#cfcaca`.
7. **Slide-up settle** (29.67 s): the new scene enters already moving upward and settles over ~6 frames.

## 7. What makes it high-end (the transferable lessons)
1. **A new graphic world per clause, all from one family:** rounded corners, a warm-grey ground, and one orange accent keep wildly different scenes (3D rings, halftone dots, footage) feeling like one brand.
2. **Make abstract processes literal UI:** "describe" = chat, "turn into an app" = node graph "Connecting", "in the background" = a scrolling code log. Each metaphor is readable in under a second.
3. **Typing is the main animation:** logo, titles, prompts and CTA all type on, which matches the product promise ("just prompt it").
4. **Quiet → loud contrast:** open on near-empty space, then hit with a full-bleed 3D texture on the second clause.
5. **Morph elements between scenes** (orb → avatar, bar → pill, square → hero tile) so cuts feel like one continuous system.
6. **Snap cuts to the beat grid** (±0.1 s) while letting words land inside the shot; keep transitions as plain cuts and put the motion inside the shot.
7. **Insert one human moment** (footage + glass caption pill) at the emotional word ("your idea") to break the UI monotony.
8. **The CTA uses the same grammar** (typing, reel, selection handles) but changes the texture (a tactile flat-lay desk), so the handoff to the creator feels native.

## 8. Remotion rebuild recipe
- **Composition:** `1920×1080`, `30 fps` (the 18 fps delivery is a re-encode; animate at 30), duration = VO + 0.3 s ≈ 960 frames. For 9:16, scale the UI elements to ~85% of the width and stack the split layouts vertically.
- **Layer stack (typical UI scene):** `<Ground color="#ebe8ec">` → `<UIElement>` (bar / bubble / card, `borderRadius: 18`, `boxShadow: 0 4px 12px rgba(0,0,0,.08)`) → `<TypeOn>` → `<Cursor>` → optional `<GlowSweep>`.
- **Components & timings (30 fps):**
  - `TypeOn({text, startFrame, cps: 25–40, caretColor:'#f96c32', caretBlink: 16})`: substring by frame; schedule from whisper word starts so keywords complete on their spoken word.
  - `LogoType({mark, word:'Base44', perLetter: 2})` + `OrbitDots({r: 60, fadeIn: 6})`.
  - `RippleRings({count: 3, gradient:['#fac0cc','#f77d6d','#f85739','#ff1a1a'], depth: 40})`: SVG/Three.js extruded torus rings (or stacked CSS ellipses with an inner shadow); scale `spring({damping: 20, stiffness: 300})` for the 3-frame burst, then `+0.3%/frame` linear.
  - `GradientOrb({size: 120→200, colors:['#f96c32','#7b5cff','#d4c3ff']})`: a radial-gradient div with `filter: blur(6px)`, rotating conic-gradient inside, `box-shadow: 0 0 60px #fff`.
  - `ChatBubble({side, text, drift})`, `PromptBar({text, attachments, sendAt})`: the send button turns `#a87158` for 4 frames on click.
  - `ImageStackFlyIn({srcs, from:{x:-400,y:-300,rot:-8}, toSlots})`: `spring({damping: 18, stiffness: 160})`, 1-frame stagger.
  - `ShapeMorph({from:rect, to:rect})` for orb→avatar, bar→pill, square→hero: `Easing.inOut(Easing.cubic)`, 6 frames.
  - `NodeGraph({squares: 30, palette, lines})`: each square `scale 0→1.1→1` over 4 frames, stagger 1 frame; lines draw on with `strokeDashoffset` over 6 frames.
  - `HalftoneDotGrid({rows: 7, cols: 12, palette, fillOrder:'row'})`: each dot pops over 2 frames; apply a halftone screen via an SVG `pattern` mask on each dot.
  - `ScrollingLog({rows, speed: 2.5px/f, activeRow: 'center'})` in a mono font.
  - `GlassPill({text})`: `backdrop-filter: blur(16px)`, `background: rgba(255,255,255,.18)`, `border: 1px solid rgba(255,255,255,.5)`, plus a pink linear-gradient sweep (`translateX -100% → 100%` over 6 frames).
  - `PerspectiveSwing({rotY: 0→-14deg, rotX: 0→6deg, frames: 14, easing: Easing.bezier(0.6,0,0.4,1)})` for the Automations board; `filter: blur()` on the far edge for DOF.
  - `ThumbnailVortex({cards: 12, r0: 900, r1: 420, rot0: -30})` with a 1-frame stagger and `spring({damping: 22, stiffness: 120})`.
  - `SlotReel({words, target:'Engineering It', frames: 18, easing: Easing.out(Easing.cubic)})`.
  - `SelectionHandles({rect, color:'#f7931e', size: 10})`.
  - `SlideUpSettle({from: 120px, decay: 0.75/frame})`, then `PunchIn({scale: 1.35, at: beat})`.
- **Tricky bits:** (1) Snap cut frames to `round(beat*30)` when the beat is within 4 frames of the clause start; otherwise cut on the word. (2) For the halftone dots, render a dot-screen texture once (canvas) and use it as a `mask-image` over flat circles, so they print-scan without per-frame cost. (3) The rings read as 3D because of an inner shadow: use `box-shadow: inset 0 20px 40px rgba(255,0,0,.6)` on each ellipse, plus a lighter top lip.
